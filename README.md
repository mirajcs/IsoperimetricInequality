# IsoperimetricInequality

[![CI](https://github.com/mirajcs/IsoperimetricInequality/actions/workflows/lean_action_ci.yml/badge.svg)](https://github.com/mirajcs/IsoperimetricInequality/actions/workflows/lean_action_ci.yml)
[![Docs](https://github.com/mirajcs/IsoperimetricInequality/actions/workflows/docs.yml/badge.svg)](https://mirajcs.github.io/IsoperimetricInequality/)
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20258500.svg)](https://doi.org/10.5281/zenodo.20258500)

A [Lean 4](https://lean-lang.org) formalization, checked against [Mathlib](https://github.com/leanprover-community/mathlib4), of the **planar isoperimetric inequality**: among all simple closed $C^1$ curves of perimeter $L$, none encloses more area than the circle of that perimeter, so the enclosed area $A$ satisfies

$$A \le \frac{L^2}{4\pi}.$$

The proof follows the Fourier-analytic argument of Adolf Hurwitz (1902): reparametrize the curve over $[0, 2\pi]$, expand its coordinate functions as trigonometric series, and combine Parseval's identity, Wirtinger's inequality, and the AM–GM inequality to bound the area. Every step is verified by Lean's kernel.

## Statement of need

The planar isoperimetric inequality is a landmark result absent from Mathlib. Beyond the theorem itself, this project contributes reusable **real Fourier analysis** infrastructure: Mathlib's Fourier material is built on the complex exponential basis $e^{inx}$ and the $L^2$ theory of `fourierBasis`, whereas [`Basic.lean`](IsoperimetricInequality/Basic.lean) develops the real $\{\cos nx, \sin nx\}$ series as a concrete pointwise-convergent object, proves it can be differentiated term by term, and states Parseval and Wirtinger in the elementary $\int_{-\pi}^{\pi}$ form used in textbooks. That layer is usable on its own in arguments about periodic functions, boundary-value problems, and Poincaré-type inequalities.

## Requirements

- [`elan`](https://github.com/leanprover/elan) (the Lean version manager). No system-wide Lean install is needed — `elan` reads [`lean-toolchain`](lean-toolchain) and fetches Lean `v4.27.0` automatically.
- `git`, and a network connection for the Mathlib build cache.

## Installation

```bash
git clone https://github.com/mirajcs/IsoperimetricInequality.git
cd IsoperimetricInequality
lake exe cache get   # download prebuilt Mathlib artifacts (avoids a multi-hour build)
lake build           # build and kernel-check this development
```

A successful `lake build` with no errors means every theorem in the repository has been verified.

## Usage

The library is meant to be `import`ed and its lemmas reused. The two entry points are:

```lean
import IsoperimetricInequality.Basic              -- real Fourier analysis: Parsevals_thm, Wirtingers_inequality
import IsoperimetricInequality.Adolf_Hurwitz_proof -- SimpleClosedC1Curve, area, isoperimetric_inequality
```

The top-level theorem, in [`Adolf_Hurwitz_proof.lean`](IsoperimetricInequality/Adolf_Hurwitz_proof.lean):

```lean
theorem isoperimetric_inequality (γ : SimpleClosedC1Curve 2)
    (hdc : Continuous (deriv γ.curve))
    (h_arc : IsArcLengthParametrized γ)
    (a b : ℕ → ℝ)
    (h_parseval  : ∫ t in (0:ℝ)..(2*Real.pi), (fParm γ t) ^ 2
                 = Real.pi * ∑' n : ℕ+, ((a n)^2 + (b n)^2))
    (h_wirtinger : ∫ t in (0:ℝ)..(2*Real.pi), (deriv (fParm γ) t) ^ 2
                 = Real.pi * ∑' n : ℕ+, ((n:ℝ)^2 * ((a n)^2 + (b n)^2)))
    (hsum : Summable (fun n : ℕ+ => (n:ℝ)^2 * ((a n)^2 + (b n)^2))) :
    area γ 0 γ.length ≤ γ.length ^ 2 / (4 * Real.pi)
```

`SimpleClosedC1Curve 2` bundles a parametrization `ℝ → EuclideanSpace ℝ (Fin 2)` with its period `length` and proofs that it is continuous, $C^1$, closed, periodic, and simple. `area` is the shoelace functional. The Parseval/Wirtinger hypotheses are instances of the general theorems in `Basic.lean` applied to the reparametrized coordinate function.

Key reusable results in [`Basic.lean`](IsoperimetricInequality/Basic.lean):

| Name | Statement |
|---|---|
| `Parsevals_thm` | Parseval's identity for the real trigonometric series |
| `Wirtingers_inequality` | $\int_{-\pi}^{\pi} f^2 \le \int_{-\pi}^{\pi} (f')^2$ for zero-mean $2\pi$-periodic $f$ |

## Tests

There is no separate test suite: in a Lean development the proofs *are* the tests, and correctness is established by the Lean kernel during `lake build`. The [`lean_action_ci.yml`](.github/workflows/lean_action_ci.yml) GitHub Actions workflow runs `lake build` on every push and pull request, so any break in any proof fails CI.
